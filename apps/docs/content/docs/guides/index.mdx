title: Guides Overview
description: Follow task-oriented paths through the fluo package ecosystem.
---

Guides are organized by what you are trying to build, not by package name. Use them when you need a path through multiple packages.

These are independent task references for an application that already runs. If you are learning fluo for the first time, follow the [FluoBlog tutorial](/en/docs/tutorial) before choosing an integration. You do not need to read every guide in order.

| Goal | Read |
| --- | --- |
| Learn the first module/controller/service slice | [FluoBlog tutorial](/en/docs/tutorial) |
| Choose packages for a task | [Package Selection](/en/docs/guides/package-selection) |
| Build REST APIs | [HTTP API](/en/docs/guides/http-api) |
| Move across runtime adapters | [Runtime Adapters](/en/docs/guides/runtime-adapters) |
| Validate inputs and shape outputs | [Validation & Serialization](/en/docs/guides/validation-serialization) |
| Add bearer or strategy-based auth | [Auth](/en/docs/guides/auth) |
| Add databases, Redis, cache, and queues | [Persistence](/en/docs/guides/persistence) |
| Add WebSockets or Socket.IO | [Realtime](/en/docs/guides/realtime) |
| Add events, CQRS, jobs, cron, and notifications | [Messaging & Workflows](/en/docs/guides/messaging-workflows) |
| Add metrics, health, throttling, and diagnostics | [Operations](/en/docs/guides/operations) |
| Test applications and packages | [Testing](/en/docs/guides/testing) |
| Use the CLI and generators | [CLI](/en/docs/guides/cli) |

Each guide links to the package reference pages that own the underlying contracts.
