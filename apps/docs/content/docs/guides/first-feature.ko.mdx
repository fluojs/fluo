첫 기능 실습은 이제 [FluoBlog 튜토리얼](/ko/docs/tutorial)에서 진행합니다. 모듈 등록, 검증, 테스트를 독자가 채우도록 남기지 않고, 완전한 실행 코드가 있는 단계들을 따라 하나의 게시글 API를 만듭니다.

## 첫 기능 만들기

[애플리케이션 생성](/ko/docs/tutorial/create-app)에서 시작해 다음 순서로 진행하세요.

1. [첫 게시글 응답 반환하기](/ko/docs/tutorial/first-route).
2. [명시적 DI로 모듈과 서비스 연결하기](/ko/docs/tutorial/dependency-injection).
3. [입력 검증과 오류 처리하기](/ko/docs/tutorial/validation-errors).
4. [테스트로 요청 동작 확인하기](/ko/docs/tutorial/testing).

전체 과정에서 같은 FluoBlog 프로젝트를 사용합니다. 각 장은 필요한 출발 상태, 정확한 파일 변경, 기대 응답, 복구할 수 있는 완성 코드를 제시합니다.

## 기존 애플리케이션에 기능 추가하기

이미 실행 중인 앱이 있다면 [기능 구조 레퍼런스](https://github.com/fluojs/fluo/blob/main/docs/getting-started/first-feature-path.ko.md)에서 모듈 등록과 파일별 책임을 확인하세요. 추가할 기능에 따라 [HTTP API](/ko/docs/guides/http-api), [검증과 직렬화](/ko/docs/guides/validation-serialization), [테스트](/ko/docs/guides/testing)를 참고하세요.

[RealWorld API 예제](/ko/docs/examples/realworld-api)는 별도 참고 애플리케이션이며 튜토리얼 프로젝트의 다음 상태가 아닙니다.
