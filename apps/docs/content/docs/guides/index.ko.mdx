---
title: 가이드 개요
description: fluo 패키지 생태계를 작업 중심 경로로 따라갑니다.
---

가이드는 패키지 이름이 아니라 만들려는 결과를 기준으로 구성됩니다. 여러 패키지를 함께 사용해야 할 때 이 섹션에서 경로를 찾으세요.

이미 실행 중인 앱에서 참고하는 독립적인 작업 문서입니다. fluo를 처음 배운다면 연동을 고르기 전에 [FluoBlog 튜토리얼](/ko/docs/tutorial)을 따라가세요. 모든 가이드를 순서대로 읽을 필요는 없습니다.

| 목표 | 읽을 문서 |
| --- | --- |
| 첫 module/controller/service slice 배우기 | [FluoBlog 튜토리얼](/ko/docs/tutorial) |
| 작업에 맞는 패키지 선택 | [패키지 선택](/ko/docs/guides/package-selection) |
| REST API 만들기 | [HTTP API](/ko/docs/guides/http-api) |
| 런타임 어댑터 이동 | [런타임 어댑터](/ko/docs/guides/runtime-adapters) |
| 입력 검증과 출력 형태 구성 | [검증과 직렬화](/ko/docs/guides/validation-serialization) |
| bearer 또는 strategy 기반 인증 추가 | [인증](/ko/docs/guides/auth) |
| 데이터베이스, Redis, cache, queue 추가 | [영속성](/ko/docs/guides/persistence) |
| WebSocket 또는 Socket.IO 추가 | [실시간](/ko/docs/guides/realtime) |
| event, CQRS, job, cron, notification 추가 | [메시징과 워크플로](/ko/docs/guides/messaging-workflows) |
| metrics, health, throttling, diagnostics 추가 | [운영](/ko/docs/guides/operations) |
| 애플리케이션과 패키지 테스트 | [테스트](/ko/docs/guides/testing) |
| CLI와 generator 사용 | [CLI](/ko/docs/guides/cli) |

각 가이드는 하위 계약을 소유하는 패키지 레퍼런스로 연결됩니다.
