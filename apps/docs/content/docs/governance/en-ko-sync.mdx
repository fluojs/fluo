---
title: Website language policy
description: English-only website publishing and bilingual repository source ownership.
---

The official website is English-only. All pages use the `/docs` path without
a language selector. Previous `/en/docs` and `/ko/docs` URLs redirect to English.
Repository documentation, package READMEs and the Book keep their bilingual
authoring policy.

## Source ownership

- Do not add translated website pages or navigation metadata.
- Preserve Korean repository documents, package READMEs and Book chapters.
- Keep public behavior aligned with the owning contracts in both repository languages.

## Verification

`pnpm docs:sync-check` walks `apps/docs/content/docs` and rejects translated
website filenames. It does not check translation meaning in repository sources.

The separate platform governance gate checks contract-specific evidence.
Review commands, defaults, limitations and expected responses against their
owning repository documents even when these gates pass.

## Tutorial source ownership

The [three-volume Book series](https://github.com/fluojs/fluo/blob/main/book/README.md) is the source for the complete product and pattern learning path. The [short FluoBlog exercise](/docs/tutorial) is a companion for checking the initial HTTP path. Review the entire Korean manuscript first, then translate it into English while preserving chapter/section structure and every code and command block.

Complete source examples use a `fluo-tutorial-source` MDX comment followed by a code fence. The marker names the file under `examples/fluo-blog/`; the website must print that tested file unchanged. Short explanatory excerpts do not carry this marker.

From the repository root:

```bash
pnpm vitest run examples/fluo-blog tooling/governance/verify-platform-consistency-governance.test.ts
pnpm book:check
pnpm verify:docs
```

The source-copy test checks shipped code equality, not prose. The example tests check the checkpoints' behavior. Also follow a changed lesson from its stated starting point: these checks cannot prove that an instruction tells a beginner where to put a file.
